### Fixed

- If the app could not tell whether Dark Souls II was running, it took that as "not running" and wrote anyway. It now refuses and says it could not check. On Windows it reads the process list directly instead of starting `tasklist`.
- Before a save is written, the app reads the encoded file back and now checks every entry's contents in its place, not just the release and the checksums, so a file with entries shifted or swapped is never written.
