### New

- **Games** panel on the left: each installed release, where it is installed and where it keeps its saves, with the characters in every save. Game folders can also be added by hand.
- **Transfers the game accepts.** Every save carries a copy of the game's data, stamped with the game's version, and Scholar of the First Sin refused converted saves that still carried the original's ("The game version and save data version are different"). A converted save now gets the target game's own data and layout, and the Steam account of the folder it goes into. The Transfer tab walks through what goes where, for which game and which account, and lists every change before and after writing.
- **Fit to the installed game** (File tab): repairs a save that another tool converted or another player sent, after taking a backup.
- **Backups** tab: every write leaves a backup marked with its reason (by hand, before saving, before a transfer, before a restore). Take one yourself, restore one, or delete it.
- **Raw data** tab: the whole save as readable JSON that you can edit, check before it is applied, export and import; and a byte view of the decrypted data. Both open behind a warning about the risks.
- **Inventory**: the game's own item icons and carry limits, each item's in-game stats and description, and a separate catalogue for adding items.
- **Settings**: language, the summary after transfers, game folders, and About.
- **Linux and Steam Deck**: finds the saves in each game's Proton prefix, in every Steam library (the microSD card included) and in Wine, Heroic and Lutris prefixes. Ready-made packages: an installer and a portable zip for Windows, an AppImage for Linux and the Steam Deck.

### Safer

- A transfer is refused when the game saved the source after it was opened here (so the latest progress is never left behind), when the target file can't be read, or when the file would carry the other game's name.
- One character can no longer be written into its own file as the other game.

### Fixed

- Ctrl+S only writes when there is something to save.
- Slots that stay empty are no longer listed as changes, and a character replaced by its own newer copy reads as an update.
