### Fixed

- Clicking the open save again, in the list or in the file picker, threw away its unsaved changes without asking. They now stay.
- Switching to another save didn't ask when the only changes were typed in the Status tab and not yet applied (raising an attribute, for example). It now asks.
- When saving failed (the game running, or the game having written the file again), the bottom bar still said "All changes saved" and Save was disabled. The changes now show as unsaved.
- A transfer didn't carry the Status tab's unsaved changes with the character. It now does.
- After the transfer settings changed, the plan for the previous settings could stay on screen.
- Switching to another character while an inventory edit was on its way could briefly show the previous character in its place.
