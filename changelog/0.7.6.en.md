### Fixed

- Unplugging a pad, or its battery dying, while a direction was held kept the cursor moving forever; a Status value, for example, would climb to its maximum. Whatever was held is now let go when a pad goes away.
- The About links can no longer be reached with a pad, so they can't open the web browser by accident, which takes a Steam Deck out of Game Mode.
- In the file window:
  - With the on-screen keyboard open, Esc on a keyboard closes only the on-screen keyboard, not the file window beneath it.
  - In a file window opened from Settings, the pad's B now closes only the file window, not Settings with it.
  - For a file at the root of a drive, the window opens at that drive's root.
  - Linked folders (junctions on Windows, ~/.steam/steam on the Steam Deck) are listed as folders, not files.
  - A disconnected network drive no longer holds up the file window.
- With a pad, the cursor returns to whatever opened a window or the on-screen keyboard once it closes, also through nested windows (Settings → file window), one step at a time.
