### First release

- Opens Dark Souls II and Scholar of the First Sin saves; tells the release apart by the key that opens the save.
- Status tab: name, souls, journey and attributes, shown like the Level Up screen.
- Inventory tab: categories, reinforcement and infusion; change counts, remove and add items.
- Transfer tab: convert a whole save to the other release, or move one character into a slot of another save.
- File tab: Steam account, checksums and the block version table.
- Never writes while the game runs, and backs up before every write.
- The interface is drawn in the game's own menu font.
