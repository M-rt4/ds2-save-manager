### New

- **Inventory changes are visible.** Items added since the save was read from disk are marked "New"; items whose quantity, reinforcement or infusion changed are marked "Changed". Removed items stay listed, struck through as "Removed", until the save is written. Changed numbers turn blue as on the Level Up screen, and an opened row shows the old and new value.
- Each change can be undone on its own. The toolbar sums up the unsaved changes and can show only what changed, and the category list marks the categories with changes.
- Edits made in the raw data and JSON views are marked the same way. The marks clear once the save is written, reloaded or its changes discarded.
