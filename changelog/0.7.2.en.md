### Fixed

- Closing the window with the title bar's X, Alt+F4 or the taskbar threw away unsaved changes without asking. It now asks first, and closes at once when nothing is unsaved. Settings → Quit asks that question only once.
- With a pad, pressing up from a backup's Restore button couldn't get back to that backup's row.
- If reading the file again failed after "Fit to the installed game" had written it, only the error showed. The finished write is now always reported.
